# Banking Management System

## Problem Statement

Managing banking activities manually can take time and may lead to errors while handling customer and transaction information. A simple computer-based system can help manage basic banking operations in an organized way.

The Banking Management System is developed to provide a simple command-line system for managing customer accounts and performing common banking operations.

## Scope of the Project

The project covers basic banking operations such as creating accounts, managing customer information, checking account balances, depositing money, withdrawing money, transferring money and viewing transaction details.

The system is designed as a command-line Java application and focuses on demonstrating basic Java programming and object-oriented programming concepts.

## Target Users

The main target users of the system are:

* Bank customers
* Bank administrators

## High-Level Features

* Customer account creation
* Customer information management
* Account balance checking
* Money deposit
* Money withdrawal
* Money transfer
* Transaction history
* Admin account management
* User authentication
* Input validation and error handling

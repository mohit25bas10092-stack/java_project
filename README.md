# Banking Management System

## Project Overview

The Banking Management System is a Java based command-line project developed to perform basic banking operations. It allows users to create and manage bank accounts and perform common transactions such as depositing money, withdrawing money, transferring money and checking account balance.

## Features

* Create a new bank account
* Manage customer details
* Check account balance
* Deposit money
* Withdraw money
* Transfer money
* View transaction history
* Admin account management
* User login
* Input validation and error handling

## Technologies Used

* Java
* Object-Oriented Programming
* Java Collections
* Exception Handling
* File Handling
* Git and GitHub

## Project Structure

The project is divided into different Java classes so that each part of the banking system can be managed separately.

## Requirements

* Java JDK
* Command Prompt / Terminal
* Git (for version control)

## How to Run

1. Install Java JDK on the computer.
2. Download or clone this repository.
3. Open the project folder in Command Prompt or Terminal.
4. Compile the Java files.
5. Run the `Main` class.
6. Follow the instructions displayed on the screen.

## Testing

The project will be tested using different inputs such as valid and invalid account numbers, deposits, withdrawals, transfers and login details.
